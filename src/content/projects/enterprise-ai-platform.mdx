## Brief

My work at AssistX Enterprise covers three connected products: a RAG and document-intelligence platform, an agentic AI assistant, and an AI-powered CRM that now runs on both. I work across the retrieval and LLM pipeline, backend services, and frontend, directly with clients and leads. This case study describes the engineering scope and stack without exposing internal product names, customer information, private endpoints, or repository links.

## Public product context

AssistX Suite is publicly presented as an intelligent document-processing platform: it analyzes document structure, classifies inputs, extracts validated fields with confidence scoring, and automates downstream workflows. The public product page is linked below; the implementation notes here remain focused on my engineering contribution.

The public diagrams on the case-study page are product context from that same overview: they show the document-to-workflow path and the extraction handoff I worked around. They are not screenshots of customer data or private implementation surfaces.

## What I worked on

**RAG and document-intelligence platform**

- Async job API that parses, splits, chunks, classifies, extracts, tags, validates, and compares documents, with human approval gates between steps.
- VLM/PDF ingestion with page-orientation detection and correction, chunk normalization, parser batching, and LLM-based structured and nested-list extraction.
- Hybrid (full-text + vector) chunk search for retrieval, plus an entity-resolution service that deduplicates people and institutions across documents.
- React operations console for document review, scoring-table sorting and filtering, column selection, extraction profiles, and resolved-entity curation.
- **Stack:** Python, FastAPI, async SQLAlchemy, Alembic, PostgreSQL + pgvector, pg_trgm, Redis (queues and streams), MinIO, vLLM / LiteLLM (OpenAI-compatible), Qwen3-VL, PyMuPDF4LLM, RapidOCR (ONNX), OpenCV, rapidfuzz · React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, TanStack Query.

**Agentic AI assistant**

- Chat orchestrator that plans multi-step answers by calling the platform's data services as MCP tools on the user's behalf, using short-lived scoped tokens instead of the user's own credential.
- Page-aware responses and guided UI walkthroughs that help users through the console, with tool calls, results, and tokens streamed live.
- Every claim cited and checked against its source, with YAML-defined evaluation sets for regression testing.
- **Stack:** Python, FastAPI, Pydantic AI, Model Context Protocol (MCP), LiteLLM, PostgreSQL, Server-Sent Events, JWT · driver.js tours in the React console.

**AI-powered CRM**

- Customer-intelligence services and console workflows for structured ingestion, tenant-scoped RFM/persona segmentation, explainable product eligibility, data operations, privacy-safe previews, and observability.
- Now integrated with the RAG platform for document understanding and the agentic assistant for conversational access.

**Delivery and client work**

- Worked directly with clients and leads, from requirements and configuration for real document sets through to deployment.
- Hardened delivery paths with automated tests (pytest, Vitest, Playwright), Docker, GitHub Actions and Jenkins CI/CD, Prometheus metrics, structured logging, and server-side credential handling.
